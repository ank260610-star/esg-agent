# 智能体提示词使用说明

版本：v0.1.0；日期：2026-11-19。

## 需求理解

智能体服务金融专业学生与初级研究人员，分析同一企业的一至两份中文报告，聚焦六项碳排放、能源和水资源指标。核心交付是带证据的数据、可比性判断、20项披露检查、确定性评分解释、待复核清单和分析报告。评价披露质量，不评价企业完整ESG表现或投资价值。

使用一个主智能体协调工具，不要求多个Agent。模型负责检索规划、组织候选、依规则提议状态和撰写解释；业务服务负责访问控制、证据校验、计算、版本、评分与导出；用户负责登记确认与人工复核。

## 文件与加载方式

系统提示词：`harness-plugin/prompts/esg-agent.md`。将其作为主智能体系统指令加载，不作为普通报告资料入库。具体加载配置留待实际Harness版本接入后确定，本文件不假定已完成工具注册。

评分子条件、锚点与标准来源由服务端规则文件维护，经get_rulebook提供。系统提示词保留状态语义及框架说明，不重复硬编码全部20项子条件。提示词单独使用不能实现访问隔离、计算准确性或人工权限控制。

本次只交付提示词与输入模板，未搭建服务、注册工具、执行真实报告分析或验证模型效果。后续接入需核对实际工具schema与提示词中的字段、错误码及流程是否一致。

## 运行时上下文模板

以下上下文由宿主从已验证任务生成，附在系统指令之后；不得直接把用户填写的ID或报告正文提升为可信上下文。

```text
当前任务ID：{{task_id}}
当前提示词版本：esg-agent-v0.1.1
模式：{{完整评估 / 证据追问 / 复核后继续}}
用户当前请求：{{user_request}}

先调用get_task_results取得当前报告集、选定年度、revision及状态。
规则版本及适用条件从get_rulebook读取。
仅使用当前运行时实际注册的业务工具；缺少能力时明确说明。
预算及用量以宿主配置与计数为准。
```

## 用户任务模板

### 完整评估

```text
请评估当前任务已登记报告中的环境信息披露质量。
按照任务选定年度提取E01—E06，保留原始值、单位、年度、范围及原文证据。
核查跨年可比性，按当前20项试验规则提出逐项评价，并调用工具计算评分。
说明覆盖率、未知项和人工复核需求，生成带证据的中文报告及可用导出文件。
未确认可比的数据不要给普通同比，未找到的证据不要直接认定为未披露。
```

### 证据追问

```text
请根据当前任务最新结果回答：{{具体问题}}。
给出原文证据、PDF物理页码，说明事实、计算与假设的区别。
如果资料不足，请明确缺什么，不重跑无关分析。
```

### 人工复核后继续

```text
我已在用户复核页面完成修改，请读取当前任务最新版本。
检查哪些比较和检查项已失效，更新受影响结果，调用工具重新评分并导出。
说明本次变化及仍待复核的项目，确保报告与导出使用同一版本。
```

## 设计取舍与后续验证

- 原需求的登记工具及extract_metrics/evaluate_disclosure，在实施文档中细化为“网页登记＋主智能体检索和组织候选＋服务端校验”。提示词采用后者，不把不存在的自动抽取工具当作现有能力。
- 原需求提出关键词与语义检索结合；实施P0允许先用关键词/全文索引。提示词只调用search_evidence，不承诺向量检索或OCR已经实现。
- 规则为未经指导老师确认的自建试验方案。提示词不将其说成官方标准，也不新增未经核实的法规或GRI条款。
- 不把比亚迪人工参考数值写入系统提示词，避免用参考答案代替真实抽取。
- 推导指标和敏感性分析需要实际确定性工具支持。当前拟定工具接口不足以完成时保留原始数据及限制，后续补契约，不让模型自行口算填补。
- 上线前用真实工具验证：缺失符号不变0、错年度不入库、外任务证据被拒绝、解析失败不扣分、未知不误判partial、边界未明不算同比、全未知无参考分、人工修改使旧结果失效、报告注入不改变流程。
- 模型轮次、token预算、超时、权限和校验必须由运行时强制执行，不能以提示词中写了限制作为验收通过的依据。
